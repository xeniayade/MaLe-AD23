# Herzinfarkt-Vorhersage (Machine Learning)
Dieses Projekt ist im Rahmen des Moduls Machine Learning entstanden.
Es handelt sich um eine Analyse und Modellierung eines binären Klassifikationsproblems zur Vorhersage des Herzinfarktrisikos auf Basis klinischer Daten.
Das Projekt wurde aus einem studentischen GitHub-Repository exportiert. Daher ist keine vollständige Versionierung enthalten.

## Daten

Die verwendeten Daten stammen ursprünglich von Kaggle. Das originale Datenset ist jedoch nicht mehr verfügbar:  [Autor](https://www.kaggle.com/rashikrahmanpritom/datasets)

## Installation
Die benötigten Python-Pakete können über die Datei requirements.txt installiert werden:

```bash
pip install -r requirements.txt
```

## Ausführung
Das Projekt wird über ein Jupyter Notebook ausgeführt.
